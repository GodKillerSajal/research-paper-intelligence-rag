# Evaluation data attribution

The retrieval benchmark uses the SciFact test set distributed by the BEIR
benchmark. The data archive is downloaded from the official BEIR dataset host
and verified against its published MD5 before extraction. The upstream dataset
card identifies the license as Creative Commons Attribution-ShareAlike 4.0
International (CC BY-SA 4.0).
